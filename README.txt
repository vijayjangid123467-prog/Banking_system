🏦 Banking System Using Python
📌 Project Description

This is a simple Banking System developed using Python. It allows users to perform basic banking operations such as checking their bank balance, depositing money, and withdrawing money.

The project is designed for beginners to understand Python concepts like variables, loops, conditional statements, user input, and arithmetic operations.

✨ Features
1.Check Balance: View the current bank balance.
2.Deposit Amount: Add money to the bank account.
3.Withdraw Amount: Withdraw money if sufficient balance is available.
4.Exit: Exit the banking system.
5.🛠️ Technologies Used
Python 3
🚀 How to Run the Project
1.Install Python 3 on your computer.
2.Download or clone this repository.
3.Open the project folder in VS Code or any Python editor.
4.Run the Python file:
bash
python banking.py
